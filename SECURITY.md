# Security policy

Please report vulnerabilities privately with GitHub's "Report a vulnerability" button (Security tab) instead of a public issue.
The latest release is supported. You will get an answer as soon as possible and a fix release with credit if you want it.

Note for users of the CDN: pin an exact version (`@3.2.0`, never `@latest` or a branch) and add a Subresource Integrity `integrity` attribute, so a later change can never alter what your visitors load.
